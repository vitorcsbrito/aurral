---
title: Jellyfin
description: Connect Jellyfin to publish Aurral flow and shared playlists.
---

Jellyfin is an optional playback destination. Aurral publishes playlists into an existing Jellyfin music library through the Jellyfin API.

## Setup

1. Create a Jellyfin API key with access to the music library.
2. Open **Settings > Playback > Jellyfin** in Aurral.
3. Enter the Jellyfin server URL, API key, and the Jellyfin user ID that owns the playlists.
4. Add a **Jellyfin** path mapping when Aurral and Jellyfin use different filesystem paths.
5. Select **Test connection**.

Aurral creates or updates playlists for enabled flows and shared playlists when you change the Jellyfin settings or a playlist changes. It removes playlists that Aurral previously created when the corresponding flow or shared playlist is deleted or disabled.

## Matching and scans

Aurral matches tracks by exact Jellyfin library path first. It uses a unique MusicBrainz recording ID only when the path does not match. It does not use title or artist guesses.

Changing Jellyfin settings refreshes playlists and schedules a library scan in the background, without making the settings save wait for library indexing. Saving unrelated settings does not trigger this refresh. The normal library scan request also refreshes the Jellyfin library. If Jellyfin is still indexing files, Aurral retries incomplete playlists during the next few minutes.

Before automatic cleanup deletes a file, Aurral uses the API key to read every Jellyfin user's playlists and keeps any file a playlist still uses. If Jellyfin cannot be read, Aurral keeps the files and tries the cleanup again before later library scans.

The Jellyfin MVP does not start playback sessions, manage multiple Jellyfin users, or create a Jellyfin library. Keep the same music library available to both Aurral and Jellyfin, or configure the path mapping.
